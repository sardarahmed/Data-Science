RevenuePulse - Windows quick start

1. Extract this folder.
2. Double-click START_REVENUEPULSE.bat.
3. Keep the terminal window open.
4. RevenuePulse will open in your default browser.

The first start creates a private Python environment and installs dependencies.
An internet connection may be required for that first setup.

To stop RevenuePulse, close the terminal window or press Ctrl+C.
